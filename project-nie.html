◉ 故事本源

从聊斋，
到今夜

蒲松龄笔下的《聂小倩》，讲一位被妖魅挟制的女鬼在兰若寺遇见书生的夜晚。我们不是重讲这个故事——我们把它交还给夜晚本身。

取材自《聊斋志异》，保留湘剧唱腔与表演精髓，引入沉浸式空间叙事与观众互动。观众将进入「兰若寺」的构建空间，在故事现场自由穿行，成为这段人鬼情缘的见证者或参与者。

与湖南省湘剧院合作，采用沉浸式舞台与新中式演绎，观众进入一座被迷雾笼罩的古寺，在角落里遇见那些本不该遇见的人。

"不是把戏曲搬进小剧场——而是让观众走进戏曲的世界。"
"她回过头——那一刻，你才意识到，自己已经不是观众。"

◉ Signature · 艺术特色

五重东方语法

FEATURE 01
湘剧唱腔
保留传统湘剧高腔特色，在沉浸空间里回荡本来的声音。
FEATURE 02
沉浸空间
剧场改造为兰若寺虚实场景——影壁、禅房、后院、钟楼，皆可穿行。
FEATURE 03
近距离观演
观众与演员最近不足一米，呼吸与衣袖都在余光里。
FEATURE 04
互动叙事
观众的选择影响部分情节展开——留下或离开，都是答案。
FEATURE 05
东方美学
写意留白与当代空间设计融合，戏曲语言在今日被重新说出。
FEATURE 06
雾灯造境
红灯与薄雾在廊下漫开，光线不是照明，而是戏的一部分。
